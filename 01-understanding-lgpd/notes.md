# Module 1 - Understanding LGPD

Lei 13.709/2018, in force since Sept 2020. Fines only since Aug 2021.

## Basic concepts (art. 5)
- **personal data**: any info about an identified or identifiable person (name, CPF, email, IP, location...)
- **sensitive personal data**: race/ethnicity, religion, political opinion, union membership,
  health, sex life, genetic or biometric data
- **anonymized data**: can't be linked back to the person anymore -> LGPD doesn't apply
- **pseudonymized**: identifiers replaced but someone can still link it back -> still personal data
- **processing (tratamento)**: basically anything you do with data: collect, store, use, share, delete...
- **data subject (titular)**: the person the data is about

## Principles (art. 6)
purpose, adequacy, necessity (only the minimum), free access, data quality, transparency,
security, prevention, non-discrimination, accountability

## Data subject rights (art. 18)
- confirm if their data is processed
- access the data
- correct incomplete or wrong data
- anonymize, block or delete unnecessary data
- portability to another provider
- delete data processed with consent
- know who the data was shared with
- know they can refuse consent and what happens if they do
- revoke consent

## Roles
- **controller (controlador)**: decides what is done with the data
- **operator (operador)**: processes on behalf of the controller (ex: a cloud provider, a payroll company)
- **DPO / encarregado**: channel between controller, data subjects and the ANPD
- **ANPD**: the regulator. Since MP 1.317/2025 it's the *Agência* Nacional de Proteção de Dados,
  a regulatory agency linked to the Ministry of Justice
