# lgpd-fundamentals-notes

My notes from the "Fundamentos da Lei Geral de Proteção de Dados (LGPD)" course (Escola Virtual.Gov / Enap, content by Serpro, 15h).

LGPD is Brazil's data protection law (Lei 13.709/2018). As a dev I wanted to see what it means in code,
so besides the notes there are a few small Python scripts.

| Folder | Topic |
|---|---|
| 01-understanding-lgpd | basic concepts, data subject rights, roles |
| 02-data-processing | legal bases, sensitive data, children, sharing |
| 03-security-privacy | privacy, security, penalties, other laws |
| 04-implementation | implementation phases |
| code | small scripts based on the notes |

Run the scripts with `python code/<file>.py` (Python 3.10+, no extra libs).
Tests: `python -m unittest discover code`
